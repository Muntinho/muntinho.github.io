# Muntinho Sumbo — hub pessoal

Página estática para GitHub Pages. Não usa JavaScript, dependências, compilação ou recursos de terceiros.

## Publicação

1. Criar o repositório público `Muntinho.github.io` na conta `Muntinho`.
2. Carregar os ficheiros mantendo os caminhos e colocar `index.html` na raiz.
3. Em **Settings → Pages**, escolher **Deploy from a branch**, ramo `main` e pasta `/(root)`.
4. Ativar **Enforce HTTPS** quando a opção estiver disponível.

## Atualização

- Editar `index.html` para alterar o nome apresentado ou as ligações.
- Editar `style.css` para alterar o aspeto.
- Atualizar também `muntinho-sumbo.vcf` quando mudar algum dado do contacto.
- Renovar `Expires` em `.well-known/security.txt` antes de expirar, sem ultrapassar 12 meses.

Não guardar palavras-passe, tokens, chaves, documentos pessoais ou outros segredos neste repositório público.
